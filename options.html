Default behavior

Sites with no matching rule below load Direct (no proxy) by default. Change this if unmatched traffic should go through a proxy profile instead.

Proxy password encryption (optional)

By default, proxy passwords are stored unencrypted in chrome.storage.local (a browser limitation). Set a master passphrase to encrypt passwords with AES-GCM; the decryption key is kept in memory only for the current browser session.
